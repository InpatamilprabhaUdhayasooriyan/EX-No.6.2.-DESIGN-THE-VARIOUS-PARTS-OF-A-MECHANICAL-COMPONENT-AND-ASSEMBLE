# EX No.6.2.DESIGN THE VARIOUS PARTS OF A MECHANICAL COMPONENT AND ASSEMBLE
## DATE:23.11.2026

## AIM: 
To Design the various parts of a mechanical component and assemble it using a bottom-up approach then convert it into the orthographic view

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 4 GB of RAM (integrated graphics recommend 6 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## COMMANDS USED:
### Align: 
The Align tool allows you to align, distribute or organize selected elements, annotations, tags and text along the axis you specify. Furthermore, the Arrange feature will automatically neatly place your tags around the current view.
The Align plug-in for Autodesk® Revit® can help to save time while producing complex drawings with large sets of annotation.
Just select a few elements and the Align tool will sort them for you.

### Derive:
Insert design elements such as Components, Bodies, Sketches, Work geometry, Flat patterns or parameters from another design.
The inserted elements update with changes to the original design

### Move: Moves the selected face, body, sketch, or construction geometry a specified distance or angle.
Select the objects to modify then specify the distance or angle. Use set pivot to reposition the manipulator

## PROCEDURE:
PROCEDURE:
STEP 1:
Open Autodesk Fusion 360 and create a new design. Select the Front Plane and start a sketch.

STEP 2:
Using the 2-Point Rectangle tool, draw a rectangle for the chair seat and click Finish Sketch.
<img width="60" height="52" alt="image" src="https://github.com/user-attachments/assets/6350f789-66d4-4ed0-8639-09cd77d3b82f" />

STEP 3:
Select the rectangle sketch and use the Extrude command to extrude the seat.
<img width="52" height="47" alt="image" src="https://github.com/user-attachments/assets/e662c0c3-d2a8-4f1c-9dc4-648edbc9e804" />

STEP 4:
Select the bottom face of the seat and draw a small rectangle of 6 mm × 6 mm at one corner.

STEP 5:
Use the Rectangular Pattern command to create the same small rectangles at all four corners of the seat. Click Finish Sketch.
<img width="375" height="25" alt="image" src="https://github.com/user-attachments/assets/cbfc180b-a400-4e2f-bec8-5d98ad2d718b" />

STEP 6:
Select the four corner rectangles and use the Extrude command to extrude them by 40 mm to create the chair legs.

STEP 7:
Select the sketch tool and draw a line from the left corner of the rectangle to a height of 56 mm. Create the back support with a width of 6 mm.

STEP 8:
Use the Extrude command to extrude the back support to the required thickness.

STEP 9:
Draw a small rectangle for the chair backrest support and extrude it to form the horizontal support.

STEP 10:
Complete the chair model by checking all the parts and save the design in Autodesk Fusion 360.
